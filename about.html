About

Background, focus areas, and the values I try to build with.

I'm a third-year, first-semester CSE student at the University of Asia Pacific, and I've been at it since 2024. My coursework and side projects both circle the same question: how do you build software that actually holds up — correct under load, and hard to break into.

That question pulls me toward three areas in particular: systems programming close to the machine, defensive security practices that anticipate misuse, and database design that keeps data honest. I like problems where the constraints are real, not theoretical.

Code quality

Readable, tested code over clever code. I'd rather ship something maintainable than something merely working.

Security first

I think about failure modes and misuse cases while designing, not after something breaks.

Honest learning

I label what I know, what I'm still learning, and what I've only read about — no inflated claims.

Collaboration

Good software is a team effort. I write for the next person reading the code, including future me.
